# プロジェクト概要 (300文字以内)

「ResiliRoute」は、平時の出張費ガバナンス（FinOps）と有事の首都直下地震BCP（人命救助・群衆分散）を統合した自律型モビリティ管制基盤です。平時は「駅すぱあと」MCPと旅費規程RAGにより新幹線指定席を自動判定し出張経費を23.6%削減。気象庁J-Alert受信時には0.1秒で緊急赤色モードへシフトし、新宿駅の群衆ボトルネック積分（0.92超）を検知して構内進入を遮断、社員120名を3大安全回廊へ1:1個別分散誘導します。Google Cloud RunとGemini 3.8 Flash、3D音声管制官アバターにより、企業の経済性と防災レジリエンスを両立します。
