# 課題と解決 (800文字以内)

【課題】
企業のモビリティ管理において、平時の「出張旅費精算（FinOps）」と有事の「災害BCP・避難誘導」は別々の部署・ツールで分断されていました。その結果、平時はグリーン車等の過剰申請による経費膨張や手動審査の手間が発生し、有事には首都直下地震発生時に鉄道が麻痺した新宿等の主要駅へ社員が殺到する群衆雪崩・圧死リスクや、外出先での孤立社員の救援遅延という致命的な人命リスクを抱えていました。

【解決アプローチ】
ResiliRouteは、この分断を解消する自律型モビリティ管制エンジンです。
1. 平時FinOps自律決裁：社員の自然言語申請をCloud DLPで機密マスキング後、Gemini 3.8 Flashと「駅すぱあと」API MCPサーバーが連携。社内旅費規程第14条に基づき普通車指定席へ自動調整し、1件あたり4,470円（23.6%）のコスト削減と即時電子決裁を実行します。
2. 0.1秒J-Alert BCP群衆分散：緊急地震速報受信時、0.1秒で緊急赤色モードへ移行。新宿駅の群衆ボトルネック指数が0.70を超えた瞬間に駅構内進入を遮断し、社員120名を明治神宮や新宿御苑などの3大安全回廊へ均等分散する1:1個別避難チケットとQRコードを自動発行します。
3. 外勤孤立者救援：六本木等での道路孤立SOSに対し、300m圏内の特等級耐震提携ビル（森タワー）を即座にマッチングし、ターンバイターン徒歩ナビと入館QRパスを発行します。
4. 3D音声管制官：Google Gemini Native TTS（WAV音源）と連動したThree.js 3Dアバターがリアルタイムに音声指示を行い、視覚・聴覚両面で安全を確保します。
